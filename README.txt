# Campus Blog

A beginner-friendly college blogging website built with HTML, CSS and JavaScript.

## Features
- Responsive multi-page design
- Home, Blogs, Events, Create Blog, About and Contact pages
- Create and publish blogs
- Local Storage for saved blogs
- Search and category filtering
- Like button
- Dark/light mode
- Mobile navigation

## How to run
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. Use `Create Blog` to add your own posts.

## Project technologies
HTML5, CSS3, JavaScript and Browser Local Storage.
